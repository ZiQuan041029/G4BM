# 🧠 G4BM (GreatMind 4 Biz Moms)

> An AI-powered mental health and wellness mobile application designed to support the unique challenges of working mothers.

## 🎯 The Problem
Balancing a career and motherhood creates immense psychological strain, often leaving working mothers ("biz moms") without the time or resources to seek traditional mental health support. Existing wellness apps are often generalized and fail to address the highly specific burnout, stress, and scheduling conflicts faced by this demographic.

## 💡 The Solution
Developed as a comprehensive capstone project, G4BM is a cross-platform mobile application that delivers accessible, intelligent, and empathetic mental health support. By integrating advanced generative AI into a smooth, intuitive mobile interface, the app provides real-time coping strategies, wellness tracking, and conversational support tailored for working mothers.

## ✨ Key Features

*   **Intelligent AI Companion:** Integrates Gemini AI to provide context-aware, conversational mental health support and personalized wellness advice.
*   **Cross-Platform Mobile UI:** Built with Flutter for a fluid, native-feeling user experience across both iOS and Android devices.
*   **Secure Backend Architecture:** Utilizes a robust Node.js environment to handle API requests, ensuring secure and rapid data processing.
*   **Scalable Data Management:** Employs MongoDB for flexible, secure storage of user profiles, chat histories, and wellness metrics.
*   **Targeted Wellness Tools:** Features designed specifically for the daily workflow and time constraints of business mothers.
